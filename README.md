📡 About

IPTV Player is a modern browser-based IPTV application designed for watching live television streams through a clean and responsive interface.

Built with React + TypeScript + Vite, the project focuses on delivering a smooth IPTV experience while keeping the interface simple, fast and easy to use.

The player uses HLS.js for HLS-based video playback and includes a modern component-driven frontend architecture.

🚀 Getting Started

📋 Requirements

Before running the project, install:

- Node.js
- npm

---

📥 Installation

1️⃣ Clone the repository

git clone https://github.com/amitbhardwaaj1/Iptv-player.git

2️⃣ Enter the directory

cd Iptv-player

3️⃣ Install dependencies

npm install

---

🔐 Environment Variables

Create your local environment file:

cp .env.example .env.local

Then add the required API configuration.

«⚠️ Never commit private API keys or secrets to GitHub.»

---

▶️ Run Development Server

npm run dev

The project is configured to start Vite on port 3000 and listen on all hosts.

Open:

http://localhost:3000

---

📦 Production

Build the application:

npm run build

Preview the production build:

npm run preview

Type-check the project:

npm run lint
